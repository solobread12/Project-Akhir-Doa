# 🕌 Nawaitu - Aplikasi Muslim Harian

Nawaitu adalah aplikasi mobile yang dirancang untuk menemani dan memudahkan umat Muslim dalam menjalankan ibadah sehari-hari. Aplikasi ini menghadirkan antarmuka yang bersih (*clean UI*) dan berbagai fitur esensial seperti jadwal sholat akurat, kumpulan doa lengkap, hingga pengingat kebaikan melalui ayat Al-Quran harian.

## ✨ Fitur Utama

Aplikasi Nawaitu dilengkapi dengan berbagai fitur untuk mendukung aktivitas ibadah harian:

* **🏠 Beranda (Home)**
    * **Ayat Hari Ini:** Menampilkan kutipan ayat suci Al-Quran harian untuk inspirasi dan pengingat (contoh: QS. Al-Insyirah: 5).
    * **Menu Utama Responsif:** Akses cepat ke fitur-fitur penting seperti **Al-Quran**, **Kiblat**, kalkulator **Zakat**, dan pencari **Masjid** terdekat.
* **⏰ Jadwal Sholat Akurat**
    * Penyesuaian jadwal sholat secara otomatis berdasarkan lokasi pengguna (didukung oleh sistem deteksi lokasi/kota).
    * Tampilan waktu sholat berikutnya yang disorot dengan ukuran besar beserta *countdown* (hitung mundur) menuju waktu azan.
    * Daftar waktu lengkap harian: Imsak, Subuh, Terbit, Dzuhur, Ashar, Maghrib, dan Isya.
* **🤲 Kumpulan Doa Terlengkap**
    * Direktori doa-doa yang bisa diamalkan sehari-hari (Doa Bangun Tidur, Sebelum Makan, dll).
    * **Fitur Pencarian (Search):** Memudahkan pengguna mencari doa spesifik dengan cepat.
    * **Kategori Filter:** Navigasi doa berbasis kategori seperti *Semua*, *Harian*, *Sholat*, *Rezeki*, dan *Sakit*.
